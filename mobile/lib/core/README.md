# core/

- `theme/`   — SixthSense colours (from the logo) and typography.
- `offline/` — on-phone journey timers, SMS fallback, low-battery mode (P1-W3..W5). The phone must work alone.
- `crypto/`  — device-bound keys (Keystore / Secure Enclave), E2E location (P1-W6).

# features/
One folder per user-facing area: onboarding, contacts, journey, walk, map, reports, companion.
